About Mini E-Commerce

Mini E-Commerce is a DBMS course project built to demonstrate a working relational database behind a real online shopping flow — user and dealer accounts, product listings, a shopping cart, order checkout, order status tracking, wishlists, and buyer–seller messaging.

Every action on this site — logging in, publishing a product, placing an order, saving to a wishlist, sending a chat message — is stored in and read back from a SQL database on the backend, not just in the browser. That's what lets two different people, on two different devices, see the same live data.

How it works

  • Users browse products, add them to cart, checkout, track orders, save wishlists, and message dealers.
  • Dealers publish and manage their own product listings and update order status as items are packed and shipped.
  • All data lives in a single shared SQLite database, accessed through a REST API.
